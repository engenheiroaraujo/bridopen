# Identidade visual

Este diretorio contem apenas um logo placeholder (`logo.svg`), usado como
favicon e como marca nas paginas publicas.

Ao subir sua propria instancia, substitua `logo.svg` pelos arquivos da sua
marca e ajuste as referencias em:

- `views/templates/base.html` e `views/templates/base-auth.html` (favicon)
- `views/templates/partials/auth-layout.html`
- `views/templates/partials/site-footer.html`
